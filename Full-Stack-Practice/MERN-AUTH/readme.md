# 🚀 Auth App - Authentication Perfection

![Auth App Banner](https://img.shields.io/badge/Auth%20App-Secure%20%7C%20Fast%20%7C%20Beautiful-blueviolet?style=for-the-badge)

A complete, production-ready authentication solution built with the MERN stack (MongoDB, Express.js, React, Node.js). Features JWT-based authentication, Google OAuth 2.0, and a stunning, responsive UI.

## 🌐 Live Demo

🔗 **Deployed URL:** [https://user-auth-48zw.onrender.com](https://user-auth-48zw.onrender.com)

---

## ✨ Features

### 🔐 Authentication
- **JWT Token-based Authentication** - Secure and stateless
- **Google OAuth 2.0 Integration** - One-click sign-in with Google
- **Protected Routes** - Private pages for authenticated users only
- **Secure Cookie Storage** - HTTP-only cookies for enhanced security

### 🎨 User Experience
- **Beautiful UI** - Modern, responsive design with Tailwind CSS
- **Smooth Animations** - Powered by Framer Motion
- **Profile Management** - Update username, email, password, and profile picture
- **Image Upload** - Cloudinary integration for profile pictures

### 🛡️ Security
- **Password Hashing** - bcryptjs for secure password storage
- **Input Validation** - Both frontend and backend validation
- **Error Handling** - Comprehensive error messages and user feedback
